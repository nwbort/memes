# Memes

A searchable gallery of memes hosted on GitHub Pages.

**Live site:** https://nwbort.github.io/memes

## Features

- Search by quote text or person
- Click a person tag to filter by that person
- Click any image to copy it to your clipboard

## Adding memes

1. Add the image to `images/`
2. Add the quote text to `text/`
3. Add an entry to `memes.json` with `n`, `text`, `img`, and `people`
